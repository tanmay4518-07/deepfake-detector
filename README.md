# 🕵️‍♂️ Deepfake Detector

A Convolutional Neural Network (CNN) based model designed to detect deepfake images and videos. This project utilizes a custom-trained model to classify whether a given image or video frame is **real** or **fake**, aiding in the fight against manipulated media.

## 🔍 Features

- ✅ Binary classification: Real vs Deepfake
- 🧠 CNN model trained on a curated dataset of facial images
- 🖼️ Image and video frame-level analysis
- 📈 Metrics and visualizations for model performance
- 🌐 Ready to integrate with web-based or mobile frontends
